# esempi-elettronica

Esempi di elettronica e microcontrollori del canale YouTube [The Linux Nerd](https://www.youtube.com/@the-linux-nerd) — sito: [www.thelinuxnerd.it](https://www.thelinuxnerd.it).

Ogni cartella è un esempio: `schema.png` è lo schema del circuito, `sketch/sketch.ino` il codice per Arduino ( si apre con l'IDE di Arduino ). Il numero davanti al nome dà l'ordine di difficoltà.
